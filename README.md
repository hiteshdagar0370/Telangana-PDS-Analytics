# Telangana PDS Analytics
 
## Multi-Dimensional Shop Performance Clustering and Anomaly Profiling
 
### Objective
Analyze Telangana Fair Price Shops using clustering techniques to identify performance groups and anomalies.
 
### Techniques Used
- Data Analysis
- PCA
- K-Means Clustering
- DBSCAN
- Streamlit Dashboard
 
### Features
- Shop Performance Analysis
- Cluster Profiling
- Outlier Detection
- Dashboard Visualization
 
### Tools
Python, Pandas, Scikit-Learn, Streamlit, Folium
